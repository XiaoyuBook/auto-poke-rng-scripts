## 0.0.3：同步客户端重构说明

本版更新包说明与本文件，正式／时间轴入口归入火叶“自动流程”分类，并附分类指南。正式／时间轴入口、共享库、数据、1154 个标签和两份 OCR 模型均保持 0.0.2 的原始字节，上述来源与资源指纹不变。0.0.1、0.0.2 发布包保留，不覆盖旧 ZIP。

本包提供流程母本与识别资源。新版客户端在每次启动自动流程时生成独立运行工程：ECS 保留按键、等待、识图、OCR 调用和外层流程调度；已迁移的 Seed 查表、宝可梦与遇敌数据、整数计算、BINGO、投票和共同区、孵蛋反查及主脚本通用反查扫描由应用内的 Python 运行时执行。名称后处理和候选验证也由应用提供。仍留在 ECS 的其他计算入口沿用原流程。

原计算库继续作为生成器的输入。生成器从当前安装包提取数据和函数签名，写入运行工程的数据快照与同名 Python 接口，并保存原 ECS 审计副本。不要从包中直接删除或手工替换这些库；仅有接口声明而缺少快照的包不能替代当前母本。

脚本包与客户端分别更新。只安装 0.0.3 不会升级客户端的 Python 实现；更新客户端后需重新启动应用、重新开始自动流程，生成新工程。已有 `.frlg-runs/` 工程保留生成时的快照。原版入口仍供生成与审计使用，Python 迁移通过客户端自动流程接入。

专用 Tesseract 模型保留作来源资源，实际 OCR 使用客户端共享 PP-OCR。此版本没有新增游戏路线或改变设备动作；编译、指纹和差分检查不能代替实机验收。迁移范围与验证方法见 [客户端迁移记录](https://github.com/XiaoyuBook/auto-poke-rng/blob/main/docs/FRLG_PYTHON_MIGRATION.md)。
