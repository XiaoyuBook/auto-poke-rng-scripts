# 珍钻复刻官方脚本包

适用于《宝可梦 晶灿钻石／明亮珍珠》。收录 24 个伊机控文本脚本和 7 个配套图像标签，按用途整理，原始脚本文件名和内容保持不变。

## 开始使用

1. 点击「预览安装」，核对文件变更后确认安装。
2. 回到软件的脚本库，选择对应脚本；使用自动流程时，在任务参数中选择需要的测种、推进和撞帧脚本。
3. 根据游戏语言、画面尺寸与当前进度，检查运行起点、按键和图像标签，再连接设备运行。

## 脚本分类

- **测种与识别**：普通测种、地下测种、御三家测种和训练家编号测种。
- **推进与撞帧**：普通推进、优化推进、神奥图鉴推进和御三家撞帧。
- **捕捉与反查**：定点、游走、御三家及特定宝可梦的捕捉反查。
- **定点与游走**：阿尔宙斯、达克莱伊、湖之传说、玫瑰公园等相关流程。
- **辅助工具**：取名、录屏和文字识别翻页。

## 运行前的准备

脚本按各自的游戏场景编写，并非在任何画面都能直接启动。先阅读所选脚本的注释，确认角色位置、菜单状态、按键时序和图像标签。不同版本独有的宝可梦及进度条件，以实际游戏为准。

文字识别区域、眼睛模板、校准延迟和个人任务参数由软件单独保存，安装脚本包不会代替这些设置。

## 更新与个人修改

更新前会展示文件变更。默认保留自己修改过的脚本和标签；需要恢复仓库版本时，选择「备份后使用仓库版本」。已有目录会完整备份，备份位置会显示在安装结果与日志中。

## 格式与来源

脚本使用原版伊机控兼容的 `.txt` 格式。23 个脚本与冻结的原版逐字节一致，另一个是本项目的文字识别翻页辅助脚本。文件列表中的名称就是实际安装文件名。

原始来源为 [原版项目](https://github.com/XiaoyuBook/auto-bdsp-rng)，本仓库遵循包内许可证，保留原作者与来源信息。
