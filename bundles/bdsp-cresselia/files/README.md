# 美梦神

珍钻复刻 · **0.0.2 测试版** · 定点与游走

## 安装与使用

本包只安装 `美梦神.txt`、必需资源与来源说明，可独立更新。安装位置：`珍钻复刻/美梦神/`。标签位于脚本旁的 `ImgLabel/`，共 4 个：喷雾消失了、宝可表、艾姆利多在202路、艾姆利多在水域。使用前按自己的画面核对标签。

脚本保持原始 .txt 文件名和正文，兼容原版伊机控。运行前请阅读脚本注释，核对游戏版本、运行起点、按键及画面尺寸；安装不会自动运行。

### 原脚本起始说明

> 1．进出一次祝庆市pc,背包准备好黄金喷雾（喷雾要在物品的第一个位置）
> 2．一只会瞬间移动的宝可梦和一只发光属性的宝可梦（同步凯西和海星），这两只濒死放在队首（凯西在前），一只等级在(40，49]之间的宝可梦在第三位
> 3.  有需要请修改撞帧FUNC中内容，其余内容请轻易不要动。

## 旧目录迁移

如果曾使用 `BDSP/` 大包，安装预览会列出本包需要迁移的脚本与标签。默认保留个人修改，原文件留作备份；自动流程的旧脚本路径改为本包路径。未安装本包前，原有文件继续使用。
