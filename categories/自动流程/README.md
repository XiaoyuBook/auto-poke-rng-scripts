# 自动流程

火红／叶绿按完整运行工程组织脚本。当前提供“野生／静态自动流程”包，正式与时间轴入口、共享库和配套识别资源一起安装、更新。

在火叶首页选择存档，进入自动流程设置目标、搜索方案，再选择入口并运行。按包说明准备游戏起点、队伍和道具，使用 1920×1080 原始游戏画面。流程包含启动、遭遇、捕获、识别、反查、校准与重试。

客户端根据方案生成独立工程。ECS 执行按键、等待、识图和流程调度，已迁移的查表、计算、反查与校准决策使用应用内 Python 运行时。原计算库仍供生成器读取，请保持包完整。更新客户端后需重启应用并重新开始自动流程。

当前发布入口覆盖原版支持的野生和静态路线。孵蛋与独立 SID 采集尚无独立发布包。编译与资源校验不能代替实机验收。
